# modelagem-pringles-3d
Projeto em C de modelagem e visualização tridimensional de um parabolóide hiperbólico, com simulação futura da trajetória de uma formiga sobre a superfície, utilizando funções de duas variáveis, discretização de superfícies e malhas poligonais com a biblioteca Raylib, desenvolvido para aplicação de conceitos de Cálculo II e Geometria Analítica.
